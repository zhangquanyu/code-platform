# 模块详细设计 - 元数据管理

## 1. 概述

元数据 = 枚举/字典定义（应用级），由多个元数据项组成；可被模型字段引用。对应数据库表 `dev_metadata`、`dev_metadata_item`。

## 2. 前端界面设计

### 2.1 页面清单

| 路由 | 页面 |
| --- | --- |
| `/metadata` | 元数据列表页 |
| `/metadata/:id` | 元数据详情页（基本信息 + 元数据项编辑 + 引用查看） |

### 2.2 元数据列表页

- 搜索区：所属应用、关键字（名称/编码）、状态。
- 表格列：名称、编码、所属应用、状态、项数（统计）、创建时间、操作。
- 「新建元数据」按钮：选择应用后创建。

### 2.3 新建/编辑元数据弹窗

- 表单：所属应用 `*`、名称 `*`、编码 `*`、描述。
- 编辑时编码与应用只读。

### 2.4 元数据详情页

**Tab 1：元数据项管理**
- 元数据项表格：
  | 列 | 说明 |
  | --- | --- |
  | 项编码 | 可编辑 |
  | 项名称 | 可编辑 |
  | 项值 | 可编辑 |
  | 启用状态 | switch |
  | 排序 | number / 拖拽 |
  | 操作 | 上移 / 下移 / 删除 |
- 顶部操作：新增项、批量保存。
- 支持行内编辑或侧栏编辑两种模式（建议行内，直观）。

**Tab 2：引用查看**
- 展示该元数据被哪些模型字段引用的列表：
  - 模型名称、字段名、字段显示名、所属微服务。
  - 点击跳转至模型详情页。

## 3. 后端接口设计

**Base：** `/api/v1/metadata`（元数据）；`/api/v1/metadata-items`（元数据项）。

### 3.1 分页查询元数据列表

- **GET** `/api/v1/metadata`
- **Query：** pageNum, pageSize, keyword, status, applicationId
- **响应：** `PageResult<MetadataVO>`
  ```ts
  interface MetadataVO {
    id: number
    applicationId: number
    applicationName: string
    name: string
    code: string
    description: string | null
    status: 0 | 1
    itemCount: number
    createTime: string
  }
  ```

### 3.2 按应用查询元数据（下拉选择）

- **GET** `/api/v1/metadata/by-application/{applicationId}`
- **返回：** 简要列表（仅启用）。

### 3.3 元数据详情（含项）

- **GET** `/api/v1/metadata/{id}` → 返回元数据 + items 数组 + 引用列表。

### 3.4 创建/更新/删除元数据

- **POST** `/api/v1/metadata`（创建）
- **PUT** `/api/v1/metadata/{id}`（更新）
- **DELETE** `/api/v1/metadata/{id}`
  - 校验：若被任何模型字段引用 → 63001「元数据已被引用，无法删除」。

### 3.5 状态切换

- **PUT** `/api/v1/metadata/{id}/status` → `{ status }`

### 3.6 引用查询

- **GET** `/api/v1/metadata/{id}/references`
- **返回：**
  ```json
  [
    { "modelId": 1, "modelName": "订单", "fieldId": 10, "fieldName": "status", "displayName": "订单状态", "microserviceName": "订单服务" }
  ]
  ```

### 3.7 批量保存元数据项

- **POST** `/api/v1/metadata/{id}/items/batch-save`
- **请求体：**
  ```json
  {
    "items": [
      { "id": null, "itemCode": "CREATED", "itemName": "已创建", "itemValue": "10", "sortOrder": 1, "status": 1 }
    ],
    "deletedItemIds": [100]
  }
  ```
- **校验：**
  - `itemCode` 在同一元数据内唯一。
  - 若被引用的元数据项被删除或停用 → 63002「存在引用元数据项，禁止删除/停用」。

### 3.8 单项 CRUD（可选）

- POST / PUT / DELETE `/api/v1/metadata-items/{id}`

## 4. 领域对象

### Entity

- `Metadata`（id, applicationId, name, code, description, status）
- `MetadataItem`（id, metadataId, itemCode, itemName, itemValue, sortOrder, status）

### DTO

- `MetadataCreateCmd`、`MetadataUpdateCmd`
- `MetadataPageQuery`
- `MetadataVO`、`MetadataDetailVO`（含 items + refs）
- `MetadataItemVO`、`MetadataItemBatchSaveCmd`
- `MetadataRefVO`

## 5. 关键业务逻辑

1. 应用唯一性：`applicationId + code + is_deleted=0`。
2. 删除/停用前置校验：查询 `dev_model_field.metadata_id` 是否引用。
3. 若仅停用元数据（不删除），允许保留已引用，但新建模型字段下拉不再包含停用元数据。
