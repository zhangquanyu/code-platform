# 开发平台需求文档 - 模型管理

## 1. 模块概述

模型相当于数据表结构的定义，隶属于微服务，由多个字段组成，等同于"表与字段"的关系。模型用于规范微服务内的数据结构，为服务参数定义与数据存储提供基础。

模型管理模块负责模型的创建、维护、查询，以及模型下字段的管理与校验。

## 2. 核心概念

- **模型**：数据结构定义，相当于一张数据表。
- **字段**：模型的组成单元，相当于数据表的列，具备数据类型与约束属性。
- **主键字段**：用于唯一标识模型记录的字段，一个模型至少包含一个主键字段。
- **枚举字段**：数据类型为枚举的字段，可关联元数据以约束取值范围。

## 3. 功能需求

### 3.1 模型基本信息维护

- 支持维护模型的基本信息，包括但不限于：模型名称、模型编码、模型描述。
- 模型编码在同一微服务内唯一。

### 3.2 模型创建/编辑/删除/查询

- **创建**：在指定微服务下新建模型，录入基本信息并保存。
- **编辑**：支持修改模型的基本信息（模型编码一经创建通常不允许修改）。
- **删除**：支持删除模型，删除前需进行关联校验（是否被服务参数引用）。
- **查询**：支持在微服务下按名称、编码检索模型列表，支持分页。

### 3.3 字段管理

- 支持在模型下新增、编辑、删除字段。
- 支持字段排序，调整字段在模型中的展示顺序。
- 支持字段属性配置，包括但不限于：
  - 字段名（系统标识）
  - 显示名（展示名称）
  - 数据类型
  - 长度/精度（适用于文本、数字类类型）
  - 是否必填
  - 是否主键
  - 是否唯一
  - 是否索引
  - 默认值
  - 字段说明

### 3.4 字段数据类型支持

- 支持常见数据类型，至少包括：
  - 文本（短文本、长文本）
  - 整数
  - 小数
  - 日期 / 日期时间
  - 布尔
  - 枚举

### 3.5 字段关联元数据

- 对于枚举类型字段，支持关联应用下的元数据。
- 字段关联元数据后，其取值范围受所关联元数据的元数据项约束。

### 3.6 模型校验与预览

- **模型校验**：保存模型时进行合法性校验，包括：
  - 模型编码在微服务内唯一；
  - 字段名在模型内唯一；
  - 模型至少包含一个主键字段；
  - 必填项配置完整。
- **模型预览**：支持以表格化形式预览模型结构与字段列表。

## 4. 业务规则

1. 模型必须归属于某一微服务，不存在无微服务的模型。
2. 同一微服务内模型编码唯一；不同微服务间允许相同编码。
3. 同一模型内字段名唯一。
4. 一个模型至少包含一个主键字段。
5. 字段关联元数据时，所关联元数据必须隶属于模型所在微服务的上层应用。
6. 枚举字段关联元数据后，取值范围受元数据项约束。
7. 删除模型时需校验是否被服务参数引用，若被引用应阻止删除或告警（建议默认阻止并提示）。

## 5. 与其他模块关联

- **模型 1:N 字段**：一个模型由多个字段组成。
- **字段关联元数据**：模型字段可关联元数据以约束取值。详见 [04-元数据管理](04-元数据管理.md)。
- **被服务参数引用**：服务的入参/出参类型可引用模型字段。详见 [05-服务管理](05-服务管理.md)。
- **向上关联**：模型归属于微服务。详见 [02-微服务管理](02-微服务管理.md)。
