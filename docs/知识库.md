# 开发平台知识库

## 项目概述

开发平台（code-platform）是一个基于元数据驱动的低代码开发平台，提供应用、微服务、模型、元数据、服务、服务编排六大模块的完整研发资产管理能力。

### DDD 分层结构

每个模块遵循以下分层结构：

```
模块目录/
├── controller/          # Controller 层：处理 HTTP 请求
├── application/         # 应用服务层：业务编排、事务控制
│   ├── application/     # AppService 实现
│   ├── converter/       # 对象转换器（MapStruct）
│   ├── dto/             # 数据传输对象
│   │   ├── cmd/         # 命令 DTO（Create/Update/Delete）
│   │   ├── query/       # 查询 DTO
│   │   └── vo/          # 视图对象（返回 VO）
│   └── domain/          # 领域层
│       ├── entity/      # 领域实体
│       ├── repository/  # 仓储接口
│       └── service/     # 领域服务
└── infrastructure/      # 基础设施层：JPA 实现、配置等
```

### 设计约束

1. **主键策略**：使用简化版雪花算法（SnowflakeConfig），保证单机唯一
2. **软删除**：所有核心业务表使用 `is_deleted` 字段（TINYINT，0=未删除，1=已删除）
3. **审计字段**：通过 Spring Data JPA Auditing 自动填充 `create_time/update_time/create_by/update_by`
4. **唯一约束**：每个模块的 code 字段在所属范围内唯一（如应用 code、微服务 code 等）

### 审计基类

```java
// BaseEntity.java - 所有实体的基类
@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
public abstract class BaseEntity {
    @CreatedDate
    private LocalDateTime createTime;      // 创建时间
    
    @LastModifiedDate
    private LocalDateTime updateTime;      // 更新时间
    
    @CreatedBy
    private Long createBy;                 // 创建人 ID
    
    @LastModifiedBy
    private Long updateBy;                 // 更新人 ID
    
    private Integer isDeleted = 0;         // 软删除标记
}
```

## 快速启动

### 1. 初始化数据库

```bash
mysql -uroot -p < code/platform-server/src/main/resources/db/init.sql
```

### 2. 启动后端

```bash
cd code/platform-server
mvn spring-boot:run
# 或指定 profile
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

后端启动后监听 `http://localhost:8080`

### 3. 启动前端

```bash
cd code/platform-web
npm install
npm run dev
```

前端启动后访问 `http://localhost:5173`

## 关键特性

### 1. 应用管理
- 应用创建、编辑、删除、状态管理
- 应用下微服务和元数据的层级展示
- 应用编码唯一性校验

### 2. 微服务管理
- 微服务归属应用管理
- 微服务下模型、服务、编排的聚合展示
- 微服务编码在应用内唯一

### 3. 模型管理
- 模型字段可视化配置（类型、长度、精度、必填等）
- 模型索引定义（普通索引、唯一索引、全文索引）
- 字段关联元数据（枚举类型）

### 4. 元数据管理
- 元数据项配置（如状态枚举、类型字典等）
- 元数据项排序和状态管理
- 跨模型字段复用

### 5. 服务管理
- 服务定义（路径、方法、分类）
- 入参/出参配置（支持关联模型字段）
- 服务参数校验规则

### 6. 服务编排
- 可视化流程编排（基于 LogicFlow）
- 节点类型：START、SERVICE、CONDITION、LOOP、END
- 节点连线和条件表达式
- 编排参数映射（入参/出参）
- Mock 执行模式（后续可接入真实 HTTP 转发）

## 开发注意事项

### 1. 跨域配置
- 开发期后端已开放 `/api/**` 跨域
- 前端 Vite 也配置了代理，二者择一即可

### 2. 鉴权预留
- 当前未接入鉴权，接口可直接访问
- `AuditorAwareImpl` 预留了用户上下文接入点（当前 Mock 返回用户 ID=1）

### 3. 编排调试
- 当前为 Mock 执行模式
- 按节点顺序遍历并对 SERVICE 节点生成 mock 出参
- 后续可接入真实 HTTP 转发

### 4. 数据库初始化
- 使用 `init.sql` 脚本初始化表结构
- 默认数据库名 `code_platform`
- 可在 `application.yml` 中修改连接信息

### 5. 多环境配置
- `application.yml` - 默认配置
- `application-dev.yml` - 开发环境
- `application-prod.yml` - 生产环境
- `application-h2.yml` - H2 内存数据库（免 MySQL 运行）

## 扩展开发指南

### 新增模块步骤

1. **定义领域实体**：继承 `BaseEntity`，添加业务字段
2. **定义仓储接口**：继承 `JpaRepository`
3. **定义 DTO**：
   - `cmd/` 下定义创建/更新命令
   - `query/` 下定义查询条件
   - `vo/` 下定义返回视图
4. **实现应用服务**：处理业务逻辑和事务
5. **实现转换器**：使用 MapStruct 定义 Entity/DTO/VO 转换
6. **实现 Controller**：定义 RESTful 接口
7. **前端实现**：
   - `api/` 下定义接口调用
   - `views/` 下实现页面组件
   - `router/` 下配置路由
